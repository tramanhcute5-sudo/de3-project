
# ĐỒNG HỒ HỌC TẬP POMODORO

## 1. Giới thiệu
Đây là chương trình đồng hồ học tập Pomodoro được viết bằng Python.
Chương trình giúp người dùng quản lý thời gian học tập và nghỉ ngơi.

## 2. Chức năng
- Nhập tên môn học.
- Tùy chỉnh thời gian học.
- Tùy chỉnh thời gian nghỉ.
- Đếm ngược thời gian học và nghỉ.
- Hiển thị thanh tiến độ học tập.
- Thống kê số phiên Pomodoro đã hoàn thành.
- Lựa chọn tiếp tục hoặc kết thúc chương trình.

## 3. Công nghệ sử dụng
- Ngôn ngữ lập trình: Python.
- Thư viện: time.

## 4. Cách sử dụng
1. Chạy file Python.
2. Nhập tên môn học.
3. Nhập thời gian học và nghỉ.
4. Nhấn Enter để bắt đầu.
5. Lựa chọn tiếp tục hoặc kết thúc sau mỗi phiên học.
